# 效果页面融合流程（可复用）

> 建立：2026-10-15　触发：用户说「以后我看到有新的效果页面可以这样进行结合」
> 用途：**看到好看的网页效果 → 拆解 → 融合进自己的项目** 的标准操作流程

---

## 核心公式

```
好效果页面 = 视觉层（好看）+ 架构层（好维护）

融合策略：
  视觉层  ← 抄「最好看」的那个（提取设计 token）
  架构层  ← 抄「组织最好」的那个（提取模块化方式）
  ↓
  沉淀成共享 theme.py（可被所有项目复用）
```

> **本次实例**：视觉抄面试帝（暖色+宋体+大圆角），架构抄 Magic UI（模块化组件函数）。

---

## 五步流程

### 第 1 步：视觉拆解（提取设计 token）

打开目标页面，抓 CSS，提取**可量化的视觉参数**：

```bash
curl -sL <目标网址> -o raw/index.html
# 从 HTML 找 CSS 链接后下载
curl -sL <目标网址>/_astro/xxx.css -o raw/style.css
```

**必提取的参数表**（照抄这张表填）：

| 参数 | 说明 | 本次值（面试帝） |
|---|---|---|
| 主色/强调色 | 品牌色 | `--red:#c63a32` |
| 背景色 | 底色 | `--bg:#f7f5f0`（暖米白） |
| 字体栈 | 标题/正文 | 标题宋体，正文无衬线 |
| **标题字号** | `clamp()` 范围 | `clamp(58px,6vw,82px)` ★ |
| **卡片圆角** | 决定"高级感" | **22px** ★ |
| **卡片内边距** | 决定"呼吸感" | **42px** ★ |
| 缓动曲线 | 决定"顺滑感" | `cubic-bezier(.2,.8,.2,1)` ★ |
| 阴影 | 层次 | `0 8px 28px rgba(27,28,25,.035)` |
| 网格/纹理 | 背景细节 | 48px 方格 |
| section 间距 | 版式节奏 | 100px |

> **★ 标记的是最影响观感的三个参数**：标题字号、卡片圆角/内边距、缓动曲线。

### 第 2 步：架构分析（提取组织方式）

看目标项目**怎么组织代码**（不是怎么好看）：

| 观察点 | 本次值（Magic UI） |
|---|---|
| 组件如何拆分 | 一个组件一个文件（79 个） |
| 样式如何管理 | CSS 变量 + 工具类 |
| 如何复用 | 共享模块 + 组合 |
| 依赖策略 | 按需引入（registry 模式） |

### 第 3 步：写入 theme.py（融合）

把第 1 步的视觉参数 + 第 2 步的模块化思路写进共享模块：

```python
# 1. 设计 Token（来自第 1 步）
TOKENS = {"red": "#c63a32", "bg": "#f7f5f0", ...}

# 2. CSS（直接用第 1 步提取的参数）
def _light_css():
    return """
    h1{font-size:clamp(46px,6vw,82px);letter-spacing:-2px;...}
    .card{border-radius:22px;padding:42px;...}
    """

# 3. 组件函数（模块化，来自第 2 步）
def kpi(value, label, delay=0.0, counted=False): ...
def card(title, body, delay=0.0, tag=None): ...
def section(title, sub, content): ...
def page(title, hero, body, footer): ...
```

### 第 4 步：重构项目（应用新主题）

把各项目的 `visualize.py` 改为调用共享模块：

```python
import sys, os
sys.path.insert(0, ".../_共享模板")
from theme import page, hero, section, kpi, card

def build():
    return page(
        "页面标题",
        hero("大标题<br><em>强调</em>", "副标题", tagline="标签"),
        section("章节", "副标题", f'<div class="kpis">{kpi(100, "指标")}</div>'),
        "底部"
    )
```

**代码量应显著下降**（本次 -27% ~ -41%，因为消除了重复 CSS）。

### 第 5 步：验证（必做，不可省）

| 验证项 | 方法 | 本次结果 |
|---|---|---|
| 语法 | `python visualize.py` exit 0 | ✅ |
| **视觉** | Chrome headless 截图 | ✅ 5 张 |
| 规范符合 | 检查视觉参数是否落地 | ✅ 16/16 |
| 数字正确 | 对比 pipeline 输出与看板显示 | ✅ |
| 无障碍 | reduced-motion + noscript | ✅ |

## 渲染验证命令（固化）

```bash
CHROME="C:/Program Files/Google/Chrome/Application/chrome.exe"

# ★ 关键技巧：注入到 </head> 前（不是 </body> 前！）
#   原因：</body> 前可能命中的是 <noscript> 内的样式，JS 可用时不生效
"$CHROME" --headless=new --disable-gpu --no-sandbox \
  --window-size=1440,3800 \
  --force-prefers-reduced-motion \     # 让数字直接显示终值（避免动画截断）
  --screenshot=out.png \
  --virtual-time-budget=3000 \
  --hide-scrollbars \
  "file:///path/to/page.html"
```

**两个踩过的坑**：
1. ❌ 注入到 `</body>` 前 → 命中 noscript，不生效 → 页面空白
2. ❌ 不用 `--force-prefers-reduced-motion` → 数字动画被截断，显示中间值

## 效果清单（可直接抄的技术）

### 视觉层（面试帝系）
| 效果 | 实现 |
|---|---|
| 大字标题 | `font-size:clamp(46px,6vw,82px);letter-spacing:-2px;line-height:1.08` |
| 大圆角卡片 | `border-radius:22px;padding:42px` |
| 网格背景 | `linear-gradient(...) 1px` × 2 层 + `background-size:48px 48px` |
| 快出慢入 | `cubic-bezier(.2,.8,.2,1)` |
| 中文宋体标题 | `font-family:"Songti SC","STSong",serif` |
| 卡片悬停 | `transform:translateY(-6px)` + 阴影加深 |

### 功能层（面试帝系）
| 效果 | 实现 |
|---|---|
| 滚动渐显 | `IntersectionObserver({threshold:.16})` + `.is-visible` + `unobserve` |
| 错峰延迟 | `style="--d:.08s"` + `transition-delay:var(--d,0s)` |
| 数字滚动 | easeOutCubic `1-(1-p)**3` + rAF；**HTML 初始值写终值** |
| 进度条 | `transform:scaleX()`（不用 width） |
| 条形图进场 | 先归零，进入视口再展开 |

### 架构层（Magic UI 系）
| 做法 | 说明 |
|---|---|
| 共享模块 | `_共享模板/theme.py` 被所有项目 import |
| 组件函数 | `kpi()/card()/section()/page()` 组合出页面 |
| 设计 token | 用 CSS 变量集中管理 |
| 按需引用 | 项目只 import 用到的组件 |

```

```
