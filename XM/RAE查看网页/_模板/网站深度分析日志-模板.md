### 1.2 技术栈识别
| 线索 | 判断依据 |

```js

new IntersectionObserver(cb, {threshold: .16}) → classList.add("is-visible") → unobserve

// 2. 进度条（用 scaleX 不用 width）

// 3. 数字滚动（easeOutCubic）

// 5. 无障碍检测（必查）
window.matchMedia("(prefers-reduced-motion: reduce)").matches
```

### 6.3 ★ 真实浏览器渲染验证（必做，2026-10-15 新增）

**用系统 Chrome headless，无需装任何 npm 包**：
```bash

CHROME="C:/Program Files/Google/Chrome/Application/chrome.exe"

# 视口截图（--virtual-time-budget 是让 JS 跑完的关键！）
"$CHROME" --headless=new --disable-gpu --no-sandbox \
  --window-size=1440,900 \
  --screenshot=render-viewport.png \
  --virtual-time-budget=3000 \
  --hide-scrollbars \
  "file:///path/to/page.html"     # 或 https://目标站

# 全页截图：把高度设大
"$CHROME" --headless=new --disable-gpu --no-sandbox \
  --window-size=1440,3200 --screenshot=render-full.png \
  --virtual-time-budget=4000 --hide-scrollbars "file:///..."
```

## 七、审查（自我质疑，找自己的漏）

### 7.1 必答三问
1. **我漏了什么？** （如：keyframes 是否列全？section 是否盘点？）
2. **我的结论有证据吗？** （每个数字是否可复现？）

### 7.2 常见查找方向
- [ ] 效果类是否全部覆盖（扫 `sheen|glow|pulse|ring|sweep|scan|float|marquee|wave`）
- [ ] 是否有 `<noscript>`（无 JS 时内容是否可见）
- [ ] 装饰元素是否 `aria-hidden`
- [ ] 是否有 `!important` 滥用
- [ ] 图片是否都有 alt
