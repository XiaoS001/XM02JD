### 3.5　核心效果源码级详解

#### 3.5.1　核心效果逐条拆解（含源码）

### 效果 1：滚动渐显（reveal-on-scroll）

**这是最核心的效果**——元素滚动进入视口时，淡入 + 上移。

**HTML**：
```html
<header class="mode-declaration-head reveal-on-scroll">
<article class="mode-card mode-card-interview reveal-on-scroll" style="--d:.12s">  <!-- 错峰延迟 -->
```

**CSS**：
```css
.reveal-on-scroll {
  opacity: 0;
  transform: translateY(22px);
  transition: opacity .65s, transform .65s cubic-bezier(.2,.7,.2,1);
  transition-delay: var(--d, 0s);   /* ← 关键：每个元素可自定义延迟 */
}
.reveal-on-scroll.is-visible {
  opacity: 1;
  transform: none;
}
```

**JS（触发）**：
```js
const io = new IntersectionObserver((entries) => {
  entries.forEach(e => {
    if (e.isIntersecting) {
      e.target.classList.add("is-visible");
      io.unobserve(e.target);   // 触发一次就取消观察（性能）
    }
  });
}, { threshold: 0.16 });        // 元素露出 16% 时触发

document.querySelectorAll(".reveal-on-scroll").forEach(el => io.observe(el));
```

**精妙之处**：
- `cubic-bezier(.2,.7,.2,1)` 是**快出慢入**曲线，比默认 `ease` 更有"高级感"
- `--d` 变量让**同组元素错峰出现**（卡片 1 先出，卡片 2 延迟 0.12s）——这是"呼吸感"的来源
- `unobserve` 触发后移除监听，避免重复计算

### 效果 2：顶部滚动进度条

```html
<div class="scroll-progress" data-scroll-progress></div>
```

```js
const progressBar = document.querySelector("[data-scroll-progress]");
const update = () => {
  const el = document.documentElement;
  const total = el.scrollHeight - el.clientHeight;
  progressBar.style.transform = `scaleX(${total > 0 ? window.scrollY / total : 0})`;
};
window.addEventListener("scroll", update, { passive: true });
```

**要点**：用 `transform: scaleX()` 而不是 `width`——**GPU 加速，不触发重排**。`passive: true` 提升滚动性能。

### 效果 3：视差滚动（parallax）

```html
<div data-parallax="0.12">...</div>
```

```js
const reduced = window.matchMedia("(prefers-reduced-motion: reduce)").matches;
document.querySelectorAll("[data-parallax]").forEach(el => {
  const speed = Number(el.dataset.parallax || 0.12);
  el.style.transform = `translateY(${window.scrollY * speed}px)`;
});
```

**要点**：
- 参数写在 HTML 属性里（`data-parallax="0.12"`），改速度不用动 JS
- **尊重 `prefers-reduced-motion`**（无障碍：晕动症用户自动禁用）——这是专业度的体现

### 效果 4：数字滚动（count-up）

```html
<span data-count="2284">0</span>
```

```js
const animate = (el) => {
  const target = Number(el.dataset.count || 0);
  const start = performance.now();
  const tick = (now) => {
    const p = Math.min(1, (now - start) / 1100);   // 1.1 秒
    const eased = 1 - (1 - p) ** 3;                 // easeOutCubic
    el.textContent = String(Math.round(target * eased));
    if (p < 1) requestAnimationFrame(tick);
  };
  requestAnimationFrame(tick);
};
// 独立观察器，threshold 0.6（露出 60% 才触发）
const io = new IntersectionObserver((es) => {
  es.forEach(e => { if (e.isIntersecting) { animate(e.target); io.unobserve(e.target); } });
}, { threshold: 0.6 });
document.querySelectorAll("[data-count]").forEach(el => io.observe(el));
```

**要点**：`1-(1-p)³` 是 **easeOutCubic**——数字"冲得快、停得稳"，比线性自然。

### 4.1 滚动边界防抖（防止页面"橡皮筋"）
```js
window.addEventListener("wheel", e => {
  const atTop = window.scrollY <= 0;
  const atBottom = window.scrollY + window.innerHeight >= document.documentElement.scrollHeight - 1;
  if ((e.deltaY < 0 && atTop) || (e.deltaY > 0 && atBottom)) e.preventDefault();
}, { passive: false });   // 注意：这里必须是 false 才能 preventDefault
```

  --headless=new --disable-gpu --no-sandbox \
  --window-size=1440,900 \
  --screenshot=output.png \
  --virtual-time-budget=3000 \    # 给 JS 执行时间（关键参数）
  --hide-scrollbars \
  "file:///path/to/page.html"      # 或 https://...

- `--virtual-time-budget` 是**让 JS 跑完的关键**（否则截图时动画未触发）
- 全页截图：把 `--window-size` 高度设大（如 3200）

## 九、结论

### 8.1 为什么它"感觉好"

| 表象 | 技术归因 |
|---|---|
| 有呼吸感 | 滚动渐显 + `--d` 错峰 + 缓动 `cubic-bezier(.2,.7,.2,1)` |
| 顺滑不卡 | 只动 transform/opacity、`passive:true`、`unobserve` 释放 |
| 高级有质感 | 暖色系 + **中文宋体标题** + 31 处 letter-spacing |
| 动效克制不喧闹 | 25 个 keyframes 但每个都小幅度、短时长 |
| 加载飞快 | JS 3.38KB + 字体 0 请求 + 94 内联 SVG |
| 移动端也舒服 | 仅 2 断点 + `clamp()` 流式自适应 |

### 8.2 可复用配方（12 条）

**动画类**
1. 滚动渐显：`IntersectionObserver({threshold:.16})` + `.is-visible` + `transition:.65s cubic-bezier(.2,.7,.2,1)`
2. 错峰延迟：`style="--d:.12s"` + `transition-delay:var(--d,0s)`
3. 数字滚动：`1-(1-p)**3`（easeOutCubic）+ rAF + 1.1s
4. 扫描线：`top:0` → `top:100%` + opacity 淡入淡出
5. 光泽扫过：`background-position:-200%` → `0`
6. 印章入场：`scale(2.4)rotate(-24°)` → `scale(1)rotate(-8°)`（有"砸下"的力度感）
7. 声波复用：一套 `wave` keyframes + `animation-delay:calc(var(--i)*N)` 错峰

**性能类**
8. 进度条用 `transform:scaleX()`，不用 `width`
9. scroll 监听必须 `passive:true`
10. **零字体请求**：用系统字体栈（`"Songti SC"` 中文宋体 + `"PingFang SC"`）
11. 图标全部内联 SVG

**工程类**
12. 只留 2 个媒体断点，其余靠 `clamp()` + `grid auto-fit`

### 8.3 原站缺陷（可改进点）
- ❌ 无 `<noscript>` 降级 → JS 失败时 `.reveal-on-scroll` 内容永久不可见
  - **修复**：`<noscript><style>.reveal-on-scroll{opacity:1!important;transform:none!important}</style></noscript>`
