## 🔑 核心结论速览

**技术栈**：Astro + 单文件 CSS 73KB + **JS 仅 3.38KB** + **零动画库** + **零字体请求**

**为什么效果好**：
- 滚动渐显 + 错峰延迟 → 呼吸感
- 只动 transform/opacity + passive → 丝滑
- 暖色系 + 中文宋体标题 + 31 处 letter-spacing → 高级感
- 25 个 keyframes 全部小幅短时 → 克制

**可复用配方 12 条**：见日志 8.2 节

**发现的原站缺陷**：无 `<noscript>` 降级（JS 失败则内容不可见）

## ⚠️ 重要提醒

1. **什么时候不该用 REA**：REA 是给无源码二进制做逆向的。**网页源码本就公开**，curl 直接抓效率高得多。
2. **渲染验证用 Chrome headless**：tabbit 浏览器工具不稳定（曾连续 3 次超时），Chrome headless 一次成功且无需依赖。
3. **单一日志原则**：同一网站/任务的所有产出写进一份日志，不拆多份。
