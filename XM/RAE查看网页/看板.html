技术栈：极简到极致

对比常见做法：不用 React/Vue，不用 GSAP，不加载字体文件。

  1. 框架：Astro（资源路径 /_astro/）—— 默认零 JS 输出
  2. 样式：单文件 CSS 73KB，12 个 CSS 变量驱动全站配色
  3. 动画：零动画库，25 个原生 keyframes + IntersectionObserver
  4. 字体：@font-face 数量 = 0，全靠系统字体栈（"Songti SC" 中文宋体做标题）
  5. 图标：94 个内联 SVG，零图标请求
  6. 响应式：只有 2 个媒体断点（980px / 620px），其余靠 clamp() 流式自适应

12 条可复用配方

直接抄进自己的项目。

  1. 滚动渐显：IntersectionObserver({threshold:.16}) + .is-visible + transition:.65s cubic-bezier(.2,.7,.2,1)
  2. 错峰延迟：style="--d:.12s" + transition-delay:var(--d,0s) —— 呼吸感的来源
  3. 数字滚动：1-(1-p)**3（easeOutCubic）+ rAF + 1.1s
  4. 扫描线：top:0 → top:100% + opacity 淡入淡出
  5. 光泽扫过：background-position:-200% → 0
  6. 印章入场：scale(2.4)rotate(-24°) → scale(1)rotate(-8°)
  7. 声波复用：一套 wave keyframes + animation-delay:calc(var(--i)*N)
  8. 进度条：用 transform:scaleX()，不用 width（GPU 加速）
  9. scroll 监听：必须加 passive:true
  10. 零字体请求：系统字体栈 "Songti SC" + "PingFang SC"
  11. 图标内联：全部 SVG，省请求
  12. 断点极简：只留 2 个，其余靠 clamp() + grid auto-fit

发现的原站缺陷

能指出原站问题，说明分析足够深。

❌ 无 <noscript> 降级
所有 .reveal-on-scroll 元素初始 opacity:0，靠 JS 加类才显示。
JS 一旦失败（禁用/加载错误），全部内容永久不可见 —— 这是可用性与 SEO 风险。

✅ 修复方法（我的 Demo 已采用）：

<noscript><style>.reveal-on-scroll{opacity:1!important;transform:none!important}</style></noscript>
