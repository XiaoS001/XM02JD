DOWNLOAD & INSTALL

下载与安装

请从面试帝官网下载客户端，并根据电脑处理器选择对应安装包。选错架构可能导致应用无法启动或运行不稳定。

WINDOWS

Windows x64

适用于 Windows 10 / 11，以及 Intel 或 AMD 处理器电脑。

选择 Windows 安装包
APPLE SILICON

macOS Apple 芯片版

适用于 Apple M1、M2、M3、M4 等芯片的 Mac。

选择 macOS ARM 安装包
INTEL MAC

macOS Intel 版

适用于搭载 Intel 处理器的 Mac 电脑。

选择 macOS Intel 安装包
安装方式Windows 双击 .exe 文件，根据安装向导完成安装。macOS 打开 .dmg 文件，将“面试帝”拖入“应用程序”文件夹。

FIRST LAUNCH

首次授权

面试帝需要读取麦克风、电脑系统声音和屏幕内容，才能分别识别你与面试官的声音，并完成截图做题。首次打开时请按系统提示完成授权。

麦克风

识别你说的话，并区分候选人声道。

屏幕与系统音频录制

识别面试官声音和完成截图做题。

输入监控（Mac）

在会议软件位于前台时监听快捷键。

通知

接收余额、更新和系统消息提醒。

macOS 授权位置系统设置 → 隐私与安全性
  • 麦克风
  • 屏幕与系统音频录制
  • 输入监控
  • 辅助功能
授权后要重启

如果 Mac 首次打开时被系统拦截，请在“隐私与安全性”中找到面试帝，确认安装包来自官网后点击“仍要打开”。开启录屏、系统音频或输入监控权限后，完全退出面试帝，再重新打开客户端。

03

YOUR CONTEXT

登录、简历与项目经历

登录面试帝

打开客户端后点击“微信扫码登录”，使用微信扫码并确认授权。登录成功后会自动返回客户端。

上传简历

每个账号可以上传一份 PDF 简历，文件大小不超过 10 MB。识别后可以直接修改文字内容，服务端保存识别结果，不保存原始 PDF 文件。

回答会结合这些信息岗位 · 项目 · 技术 · 经历
  • 个人项目中承担的职责
  • 使用过的技术和业务背景
  • 目标岗位与职业规划
项目经历建议用 3—5 段写清楚项目背景、你的职责、技术方案和结果，最多填写 1000 字。内容越接近真实经历，回答越自然。
04

INTERVIEW SETUP

配置一场面试

点击首页“开始面试”，按照目标岗位填写以下内容。设置越具体，回答越贴近当前面试。

  1. 面试方向选择技术研发、产品经理、数据分析、运营、销售等方向；没有合适选项时选择“其他”。
  2. 面试岗位建议填写完整，例如“高级 Java 后端开发工程师”，不要只填写“开发”。
  3. 面试语言选择中文、English 或中英结合（自动判断）；选择中英结合时，会根据面试官当前问题的主要语言生成回答。
  4. 编程题设置技术面试建议开启，并选择面试中可能使用的代码语言。
  5. 麦克风与回答详细程度选择当前麦克风，并在简洁、标准、详细之间选择回答风格。
  6. 本场 AI 引擎可选择面试帝默认模型，或选择已经保存在本机的自有模型；每场面试和笔试都可以单独选择。
  7. 作答方式与补充背景可选择手动作答或自动 + 手动，并补充岗位 JD、公司业务和希望强调的信息。
  8. 触发话术设置一句自然的触发话术，例如“好的面试官”，说出后即可自动触发作答。
添加自有模型打开左侧“自有模型”，点击“添加模型”，依次填写配置名称、模型厂商、模型名称、API URL 和 API Key。保存前建议先点击“测试连接”；如果开启“使用该模型识别截图”，测试时还会验证图片识别能力，未开启时截图继续使用平台视觉模型。可以保存多套配置，未主动选择时仍使用面试帝默认模型；配置由系统安全存储保存在本机。
05

READY CHECK

设备确认与正式开始

进入设备确认页后，麦克风和系统音频都应显示“正常”。建议在正式面试前完成一次完整测试。

01

打开腾讯会议、飞书、钉钉或面试网页。

02

播放一段声音，确认系统音频可以识别。

03

自己说一句话，确认麦克风可以识别。

04

尽量佩戴耳机，减少系统声音再次进入麦克风。

确认两路声音都正常后，点击“正式开始面试”。
06

REAL-TIME ANSWER

实时识别与 AI 作答

面试帝使用双路流式识别：会议软件、浏览器等电脑系统声音作为面试官声道，当前选择的麦克风作为你的声道。面试官内容显示在左侧，你说的话显示在右侧，AI 回答显示在回答区域。

AS
普通作答

针对当前面试官问题生成回答建议，适合八股文、场景题和开放问题。

ASD
简历作答

结合已上传的简历和项目经历回答，让内容贴近你的真实背景。

07

AI WRITTEN TEST

截图做题

AI 笔试模式适用于算法题、编程题、SQL、选择题、报错信息、表格和架构图。无需开启语音识别，看到题目后按快捷键即可识别并生成答案。

SCREENSHOT SOLVERREADY
题目识别输入完整题干 → 分析题型 → 生成答案算法 · SQL · 数学 · 选择 · 简答
Q+W+E截图并作答
  1. 显示完整题目让题干、输入输出、示例和函数签名尽量同时出现在同一屏幕。
  2. 选择题目所在屏幕多屏用户先将鼠标移动到题目所在的显示器。
  3. 触发截图同时按下 Q + W + E，等待识别和答案生成。
截图提示代码题会优先使用面试配置中选择的编程语言。实时面试截图冷却 20 秒，笔试截图冷却 5 秒，请在一次截图中尽量包含完整题目。
08

SECOND SCREEN

副屏与布局

开始面试后点击“打开副屏”，手机、平板或另一台电脑都可以同步查看面试官问题、你的对话和 AI 回答。

面试主屏
副屏实时同步
  • 桌面端面试必须保持在线。
  • 房间码只在当前面试有效。
  • 结束面试后副屏自动退出。
  • 副屏不单独扣除面试时长，最多同时连接 2 台。

电脑副屏支持只看对话、左右分栏和只看答案；手机副屏会自动切换为上下布局，也可以拖动分隔线。

修改快捷键

进入“设置 → 快捷键”，可以修改普通作答、简历作答、截图做题、深度思考截图和唤起窗口等组合键。每组至少需要两个按键，Windows 支持主键盘数字与小键盘数字。

全局生效与隐私

快捷键在切换软件、最小化或隐藏窗口后仍可使用。macOS 请开启输入监控与辅助功能权限；“设置 → 隐私与安全”中还可以管理防截屏保护和隐藏应用图标。

10

RECORDS & EXPORT

查看与导出面试记录

结束面试后，进入左侧“面试记录”，选择一场记录即可查看面试官、候选人和 AI 回答的完整对话。记录可以直接在本机导出，不需要额外上传到导出服务。

  1. 打开面试记录在列表中选择需要整理或复盘的一场面试。
  2. 检查对话内容确认对话已经加载完整；超过保存期限并被清除的内容无法导出。
  3. 选择导出格式点击“导出记录”，选择 HTML 网页或 PDF 文档，再选择保存位置。

HTML 网页

适合在浏览器中查看，保留完整排版、左右对话气泡和代码格式，也方便后续自行编辑或打印。

PDF 文档

适合归档、打印和直接分享，导出的内容同样使用清晰的对话气泡区分不同发言人。

隐私提示导出文件可能包含面试问题、个人回答和简历相关内容，请妥善保存。删除客户端内的记录不会自动删除已经导出的本地文件。
11

FINISH & UPDATE

结束面试、充值与更新

结束面试

点击右上角“结束面试”，确认后会停止音频采集、关闭副屏并完成本场结算。余额达到 0 秒时，面试会自动结束。

购买时长

进入“时长购买”，选择套餐后使用微信扫码支付。支付成功后等待余额自动更新。

版本更新

客户端发现新版本时会展示版本号和更新说明。普通更新可以稍后处理，强制更新需完成更新后才能开始下一场面试。

12

TROUBLESHOOTING

常见问题

为什么识别不到面试官的声音？+

请确认面试官声音确实从当前电脑播放，并检查屏幕与系统音频录制权限。macOS 授权后需要完全退出并重新打开面试帝。

为什么识别不到我自己的声音？+

请在系统设置中允许面试帝使用麦克风，并在面试配置页选择当前正在使用的麦克风设备。可以先在设备确认页说一句话测试。

同一句话为什么出现了两遍？+

通常是扬声器声音同时进入系统声道和麦克风。建议佩戴耳机，并关闭虚拟声卡、立体声混音或其他会重复采集声音的设备。

出现 ASR 连接关闭 1006 怎么办？+

这通常与网络、代理、防火墙或服务连接有关。先确认网络稳定，关闭可能拦截 WebSocket 的代理后重试；客户端也会尝试自动重连。

快捷键没有反应怎么办？+

先进入“设置 → 快捷键”确认当前组合键。自定义快捷键至少需要同时按下两个按键，Windows 的主键盘数字和小键盘数字都可以使用；macOS 用户还需要开启“输入监控”和“辅助功能”权限。

截图没有识别完整题目怎么办？+

让题干、输入输出、示例和函数签名尽量同时显示在同一屏幕，并将鼠标移动到题目所在显示器后再按 Q + W + E。实时面试截图有 20 秒冷却，笔试截图有 5 秒冷却。

副屏无法连接怎么办？+

确认桌面端面试仍在线，并使用本场面试生成的房间码。房间码只在当前面试有效，结束面试后副屏会自动退出。

出现 Failed to fetch 怎么办？+

请先检查网络连接、系统时间和代理设置，然后完全退出并重新打开客户端。如果仍然出现，请记录客户端版本、操作系统和错误发生时间后联系客服。

FINAL CHECKLIST

正式面试前快速测试

  1. 完成麦克风、屏幕与系统音频录制、输入监控授权。
  2. 上传简历并检查识别后的文字内容。
  3. 如使用自有模型，先在“自有模型”页面完成连接测试，并在准备页确认本场选择。
  4. 创建一场测试面试，播放视频确认系统声音识别为面试官。
  5. 自己说话，确认麦克风识别为你。
  6. 测试普通作答 A + S、简历作答 A + S + D、截图做题 Q + W + E 和深度思考截图 Q + W + E + R。
  7. 测试副屏同步、布局切换，并正常结束面试确认余额和历史记录更新。
仍然遇到问题？

联系客服时请提供操作系统、客户端版本、会议软件、错误提示和问题发生时间。不要发送微信密码、支付密码或其他敏感信息。
