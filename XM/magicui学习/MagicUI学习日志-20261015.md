## 三、★ 核心实现原理（源码级学习）

### 3.1 最简单也最优雅：scroll-progress（35 行）

```tsx
"use client"
import { motion, useScroll } from "motion/react"

export function ScrollProgress({ className, ref, ...props }) {
  const { scrollYProgress } = useScroll()   // ← 一行拿到滚动进度 0-1

  return (
    <motion.div
      style={{ scaleX: scrollYProgress }}    // ← 直接绑定，无需手动计算
      className="fixed inset-x-0 top-0 z-50 h-px origin-left bg-linear-to-r ..."
    />
  )
}
```

**对比我之前的实现**（面试帝分析后自己写的）：
```js
// 手动计算版本（我写的）
const total = el.scrollHeight - el.clientHeight;
pb.style.transform = `scaleX(${window.scrollY / total})`;
```

**Magic UI 版本**：用 `useScroll()` 一行拿到 `scrollYProgress`（0-1 的 MotionValue），直接绑到 `scaleX`。
→ **优势**：不用手动监听 scroll、不用手动算比例、自动响应式更新。

### 3.2 数字滚动：number-ticker（75 行）★

```tsx
const motionValue = useMotionValue(direction === "down" ? value : startValue)
const springValue = useSpring(motionValue, { damping: 60, stiffness: 100 })  // ← 弹簧物理
const isInView = useInView(ref, { once: true, margin: "0px" })               // ← 进入视口检测

useEffect(() => {
  if (isInView) timer = setTimeout(() => motionValue.set(value), delay * 1000)
}, [...])

// 监听弹簧值变化 → 更新文本
useEffect(() => springValue.on("change", (latest) => {
  ref.current.textContent = Intl.NumberFormat("en-US", {...}).format(...)
}), [springValue])
```

**对比我用的方案**：

| | 我的方案 | Magic UI 方案 |
|---|---|---|
| 缓动 | 1-(1-p)**3（easeOutCubic 手写） | **useSpring（物理弹簧）** |
| 触发 | IntersectionObserver 手写 | useInView hook |
| 更新 | requestAnimationFrame 手写 | springValue.on("change") |
| 格式化 | 无 | Intl.NumberFormat（支持小数位） |

> **学习点**：弹簧（spring）比贝塞尔曲线更自然——有物理惯性感。且 damping/stiffness 参数可调「弹性」。

### 3.3 卡片跟随鼠标：magic-card（223 行）★

核心模式：
```tsx
const mouseX = useMotionValue(0)      // 鼠标 X 位置（MotionValue）
const mouseY = useMotionValue(0)
const springX = useSpring(mouseX, { stiffness: 300, damping: 30 })   // 弹簧平滑
// 用 useMotionTemplate 拼 CSS（把动态值插入模板）
const background = useMotionTemplate`radial-gradient(${gradientSize}px circle at ${springX}px ${springY}px, ...)`
```

**精妙点**：
1. **`useMotionValue`**：存鼠标坐标（**不触发 React 重渲染**！性能关键）
2. **`useSpring`**：让光晕跟随有「延迟感」，不是硬跟随
3. **`useMotionTemplate`**：把 MotionValue 插进 CSS 字符串模板
4. **双模式**（mode="gradient" / mode="orb"）：用 TypeScript 联合类型 + 类型守卫实现

```tsx
type MagicCardProps = MagicCardGradientProps | MagicCardOrbProps
function isOrbMode(props: MagicCardProps): props is MagicCardOrbProps {
  return props.mode === "orb"
}
```
> **TypeScript 技巧**：用「可辨识联合」让两个模式的 props 互斥（gradient 模式下 glowFrom 必须是 never）。

### 3.4 纯 CSS 方案：shine-border（64 行）★

```tsx
style={{
  backgroundImage: `radial-gradient(transparent,transparent, ${color},transparent,transparent)`,
  backgroundSize: "300% 300%",                    // ← 渐变放大 3 倍，才能移动
  mask: `linear-gradient(#fff 0 0) content-box, linear-gradient(#fff 0 0)`,
  WebkitMaskComposite: "xor",                    // ← 遮罩异或 → 只显示边框
  maskComposite: "exclude",
  padding: "var(--border-width)",
}}
className="motion-safe:animate-shine will-change-[background-position]"
```

**三重技巧**：
1. **radial-gradient 做光带**：中间亮、两端透明
2. **mask + xor 合成**：用两层遮罩异或，「挖空」中间 → 只剩边框发光
3. **`motion-safe:`**：Tailwind 前缀，自动尊重 prefers-reduced-motion（★ 无障碍最佳实践）

### 3.5 沿路径运动：border-beam（108 行）★★ 最有价值发现

**让光点沿边框绕行**：
```tsx
<motion.div
  style={{
    width: size,
    offsetPath: `rect(0 auto auto 0 round ${size}px)`,   // ★ CSS offset-path！
  }}
  initial={{ offsetDistance: "0%" }}
  animate={{ offsetDistance: "100%" }}                    // ★ 沿路径运动
  transition={{ repeat: Infinity, ease: "linear", duration }}
/>
```

**核心是 CSS `offset-path`（运动路径）**：
- `offset-path: rect(... round Npx)` 定义一条**圆角矩形路径**
- `offset-distance` 从 0% → 100% 就是沿路径走一圈
- **不用 JS 算坐标**！浏览器原生支持

> **这是本次学习最有价值的发现**：`offset-path` 能实现「沿任意路径运动」，是做「绕边框光束」的标准解法。

### 3.6 滚动速度感应：scroll-based-velocity（221 行）★

```tsx
const { scrollY } = useScroll()
const scrollVelocity = useVelocity(scrollY)              // ← 滚动速度
const smoothVelocity = useSpring(scrollVelocity, { damping: 50, stiffness: 400 })
const velocityFactor = useTransform(smoothVelocity, (v) => {
  const sign = v < 0 ? -1 : 1
  const magnitude = Math.min(5, (Math.abs(v) / 1000) * 5)   // ← 限幅，最多 5 倍
  return sign * magnitude
})
```

**亮点**：
1. `useVelocity` 拿滚动速度
2. `Math.min(5, ...)` **限幅**（防止滚太快动画飞掉）
3. 用 `Context` 共享 velocityFactor 给子组件（避免重复计算）
4. 导出 `wrap(min, max, v)` 函数做**循环取模**（无缝跑马灯的关键）

### 3.7 文字动画：text-animate（446 行，最复杂文字组件）

```tsx
type AnimationType = "text" | "word" | "character" | "line"   // 按什么粒度切
type AnimationVariant = "fadeIn" | "blurIn" | "blurInUp" | "slideUp" | "scaleUp" | ... // 10 种预设
```
**特性**：4 种切分粒度 + 10 种预设 + `startOnView`（进入视口才播）+ `once` + `memo` 优化 + `AnimatePresence` 进出场

## 七、可复用配方（★ 直接抄）

### 7.1 motion 惯用法

| 需求 | motion API 组合 |
|---|---|
| 滚动进度条 | useScroll() → scrollYProgress → 绑 scaleX |
| 数字滚动 | useMotionValue + useSpring + useInView + .on("change") |
| 鼠标跟随光晕 | useMotionValue（存坐标）+ useSpring（平滑）+ useMotionTemplate（拼 CSS） |
| 进入视口触发 | useInView(ref, { once: true }) |
| 滚动速度感应 | useVelocity(useScroll().scrollY) + useTransform 限幅 |
| 沿路径运动 | CSS offset-path + offsetDistance 动画 |

### 7.2 纯 CSS 高级技巧

| 效果 | 实现 |
|---|---|
| 边框发光绕行 | offset-path: rect(0 auto auto 0 round Npx) + 动画 offsetDistance 0%→100% |
| 边框高光扫过 | radial-gradient + mask 双层 + maskComposite: exclude/xor |
| 渐变文字流动 | background-size: 300% + bg-clip-text + text-transparent |
| 模糊背景光 | SVG feGaussianBlur + feColorMatrix saturate filter |

### 7.3 工程实践

1. **无障碍**：Tailwind 用 `motion-safe:` 前缀（自动尊重 prefers-reduced-motion）
2. **性能**：坐标类高频值用 `useMotionValue`（**不触发 React 重渲染**）
3. **Canvas 三件套**：requestAnimationFrame + devicePixelRatio + 清理函数
4. **类型系统**：用「可辨识联合」表达互斥的组件模式
5. **架构**：registry 模式（源码交付，代码归用户）
