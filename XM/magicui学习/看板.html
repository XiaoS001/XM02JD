★ 最有价值的发现：offset-path

border-beam 组件让光点沿边框绕行 —— 不用 JS 算坐标，纯 CSS 运动路径


// 定义一条圆角矩形路径，让光点沿它运动
offsetPath: `rect(0 auto auto 0 round ${size}px)`,

// 从 0% 走到 100%，就是沿路径绕一圈
initial: {{ offsetDistance: "0%" }},
animate: {{ offsetDistance: "100%" }},
transition: {{ repeat: Infinity, ease: "linear" }}

可复用配方

可直接抄进项目的技巧

  1. 边框发光绕行：offset-path: rect(0 auto auto 0 round Npx) + 动画 offsetDistance 0%→100%
  2. 边框高光扫过：radial-gradient + mask 双层 + maskComposite: exclude
  3. 渐变文字流动：background-size: 300% + bg-clip-text + text-transparent
  4. 模糊背景光：SVG feGaussianBlur + feColorMatrix saturate
  5. 性能关键：高频值用 useMotionValue（不触发 React 重渲染）
  6. 无障碍：Tailwind 用 motion-safe: 前缀自动降级
  7. Canvas 三件套：requestAnimationFrame + devicePixelRatio + 清理函数
  8. 无缝循环：wrap(min,max,v) 取模函数
