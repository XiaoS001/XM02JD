AI应用开发岗位知识

AI应用开发工程师的核心职责，是使用现有的大模型能力来构建应用产品。
常见的 AI 应用形式包括：聊天机器人、智能问答系统、RAG 知识库、AI Agent 等。

RAG 是检索增强生成的缩写，英文是 Retrieval-Augmented Generation。
RAG 的核心思想是：先从知识库中检索相关的文档片段，再把检索结果交给大模型生成答案。
这样做的目的是解决大模型"胡说八道"（幻觉）的问题，让回答有据可依。

RAG 的标准流程分为四步。
第一步，文档加载和切分，把长文档切成小块。
第二步，向量化，把文本块转成向量表示。
第三步，检索，用向量相似度找出最相关的块。
第四步，生成，把检索到的块作为上下文交给大模型生成回答。

向量化常用 embedding 模型，例如 OpenAI 的 text-embedding-3 系列。
检索常用余弦相似度来计算两个向量之间的相似程度。
相似度越高，说明两块文本语义越接近。

AI 应用开发工程师需要的技能包括以下四点。
第一，会用 Coding Agent 辅助开发，比如 Claude Code、Codex 等。
第二，能验证 AI 输出的正确性，对最终交付结果负责。
第三，掌握 LLM API 的调用方式，包括接口参数、流式输出、错误处理。
第四，理解 RAG、Agent、函数调用等主流技术范式。

大模型 API 调用通常使用 OpenAI 兼容的接口格式。
请求包含 model、messages 等字段，messages 里包含 system 和 user 角色。
流式输出用 stream 参数控制，可以逐字返回结果。

AI 应用开发与 AI 算法研究的区别在于：
应用开发使用现成的模型做产品，重点在工程落地；
算法研究训练和调优模型本身，重点在数学和实验。
