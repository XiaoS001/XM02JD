# P02 练手项目：GEO 关键词矩阵 + AI 引用监测 + 询盘漏斗

> 立项日期：2026-10-14
> 对应岗位：冲鸭教育「AI搜索优化师/GEO运营」
> 立项依据：HR 追问"数据怎么样"时答不出数字 → 缺可量化实战成果（JD 任职要求第 3 条）
> 技术决策：延续 P01（Python 模拟数据 + mock + 可视化），行业选日语学习（贴合 JD 场景）

## 一、一句话目标

围绕"日语学习"搭一套 GEO 优化数据工作台：关键词矩阵 → 内容埋词检查 → AI 平台引用监测 → 结构化数据生成 → 询盘漏斗，最终产出至少 6 个可报的量化数字。

## 二、四大模块与验收标准

| 模块 | 做什么 | 验收标准 |
|---|---|---|
| M1 关键词矩阵 | 围绕"日语学习"生成需求词/课程词/对比词/长尾问答词四类词库 | ≥4 类、≥60 个词，每词带搜索意图标签与竞争度评分 |
| M2 内容埋词检查 | 给定一篇内容，检查关键词覆盖密度、语义相关性 | 输出覆盖报告：命中词/缺失词/密度 |
| M3 AI 引用监测 | 模拟 5 大 AI 平台（豆包/元宝/DeepSeek/千问/文心）对品牌词的引用情况，追踪变化 | 平台×关键词引用矩阵 + 收录状态 + 变化趋势 |
| M4 询盘漏斗 | 曝光→点击→询盘→试听→成单漏斗 + 归因 | 每环节转化率 + 来源归因 |

端到端验收：一条命令跑完 M1→M4，生成看板 HTML。

## 三、必须产出的 6 个量化数字（面试弹药）

1. 关键词矩阵总量（目标 ≥60）
2. 四类词分布（需求/课程/对比/长尾）
3. 内容埋词覆盖密度（%）
4. AI 平台引用次数（分平台统计）
5. 引用变化趋势（环比 ±%）
6. 询盘漏斗各级转化率（%）
