# 信息源可达性地图（国内无代理环境）

> 实测时间：2026-10-13
> 环境：本机未开代理
> 用途：查资料时按此表选源，避免在不可达的源上浪费时间
> 维护：XiaoY，每次发现变化就更新

---

## 一、结论速览

**多数一手源直连可用**，只有 GitHub 主体、Reddit、HuggingFace 需要特殊处理。
**重大发现：`codeload.github.com` 直连可用**，可下载任意公开仓库的 tarball，绕开镜像。

---

## 二、可达性实测表

### ✅ 直连可用（无需镜像）

| 源 | 地址 | 用途 | 响应 |
|---|---|---|---|
| Hacker News API | hn.algolia.com/api/v1 | AI 圈一手讨论热点 | 200 |
| arXiv API | export.arxiv.org/api | 论文 | 200 |
| TechCrunch RSS | techcrunch.com/feed | 科技新闻 | 200 |
| The Verge RSS | theverge.com/rss | 科技新闻 | 200 |
| dev.to API | dev.to/api/articles | 开发者文章 | 200 |
| Lobsters JSON | lobste.rs/newest.json | 技术社区热点 | 200 |
| npm registry | registry.npmjs.org | npm 包信息 | 200 |
| PyPI | pypi.org/pypi/<pkg>/json | Python 包信息 | 200 |
| **codeload.github.com** | codeload.github.com/<owner>/<repo>/tar.gz/refs/heads/<branch> | **下载 GitHub 仓库源码** | 200（实测 10.9MB 成功） |

### ❌ 直连不通 / 需镜像

| 源 | 状态 | 备注 |
|---|---|---|
| api.github.com | 000 超时 | GitHub API 需镜像 |
| github.com（网页） | 不通 | trending 等网页需镜像 |
| raw.githubusercontent.com | 000 | raw 文件需镜像 |
| reddit.com | 000 超时 | 需代理 |
| huggingface.co | 000 | 需代理 |

### ⚠️ GitHub 镜像（不稳定，随时变）

| 镜像 | 实测状态 |
|---|---|
| gh-proxy.com | 曾可用，现 403（会限流/封禁） |
| ghfast.top | 403 |
| ghproxy.net | 403 |
| mirror.ghproxy.com / gh.llkk.cc / github.moeyy.xyz | 超时 |
| gitclone.com | 502 |

> **结论：镜像不可靠，优先用 codeload 直连下载代码；GitHub API 需要时再逐个试镜像。**

## 三、查资料的标准流程（固化）

1. **选源**：先按上表选直连可用的源；
2. **GitHub 相关**：
   - 查仓库元数据 → 试镜像的 api.github.com；
   - 下载代码 → **直接用 codeload.github.com 直连**；
   - 读 README → 试镜像的 raw.githubusercontent；
3. **AI 动态**：HN API（讨论热点）+ GitHub 新仓库（趋势）+ arXiv（论文）三路交叉；
4. **过滤**：时间戳 → 来源一手/二手 → 新闻/观点/营销 → 是否可复现。

## 四、关键命令备忘

```bash
# 下载任意 GitHub 公开仓库源码（直连，无需镜像）
curl -sL -o repo.tar.gz https://codeload.github.com/<owner>/<repo>/tar.gz/refs/heads/main
tar -xzf repo.tar.gz

# HN 近期 AI 高热度讨论
curl -s "https://hn.algolia.com/api/v1/search_by_date?query=AI&tags=story&numericFilters=points>100"

# GitHub 新仓库（需镜像，镜像地址前缀可变）
curl -s "https://<镜像>/https://api.github.com/search/repositories?q=created:>YYYY-MM-DD&sort=stars"
```
