# 剖解案例：软件开发实习生（Vibe Coding 方向）

> 剖解时间：2026-10-14
> 岗位：软件开发实习生（Vibe Coding 方向）· 240元/天 · 钱塘云谷 · 招聘截止 2027.12.31
> **与本岗位匹配度：极高** —— 你现在的 XM02JD 工作流就是这个岗位要的东西

---

## 一、四层剖解

| 层 | 内容 |
|---|---|
| **L1 表面** | 会用 Codex/Claude Code 等 Coding Agent 完成功能开发 |
| **L2 真实** | 不是"会用 AI 写代码"，而是**能驱动 AI 交付能跑的软件**：拆任务→AI 生成→**自己验证**→修复→交付 |
| **L3 隐藏** | ①"能检查 AI 的输出，对最终交付结果负责" = **AI 会写错，你得有验证能力兜底**；②"愿意研究和解决问题" = 卡住不放弃；③加分项 Git/数据库/接口/部署 = 工程落地能力 |
| **L4 错漏** | "Vibe Coding"听着随意，实际要求**对结果负责**——这与纯 vibe coding（不验证直接用）相反 |

## 三、打招呼策略

**核心：不聊"我会用 AI"，直接甩"我做了什么 + 怎么验证的"。** 这个岗位最稀缺的是"对结果负责"的人，用可复现的数字证明。

## 四、打招呼词（三个版本）

### 版本 A：数字流（推荐，30 秒读完）

> 您好！看到贵司招 Vibe Coding 方向实习生，我正是重度 AI 编程使用者。
> 我用 AI Agent 完成了两个**能直接跑通的项目**：①AI 获客全流程（六段 pipeline，一条命令出结果）；②GEO 关键词矩阵+AI 引用监测（62 个关键词、五大 AI 平台引用 2284 次、询盘漏斗 1015→202）。
> 每个数字都有固定种子可复现——AI 的输出我逐项验证过，还修掉 3 个指标口径 bug。
> 会 Git 和 MySQL，可到岗，方便发您作品看板吗？

### 版本 B：痛点流（针对"对结果负责"）

> 您好！我对这个岗位的理解：Vibe Coding 最难的不是让 AI 写代码，而是**检查它写得对不对**。
> 我用 AI Agent 做过两个可运行项目（获客流水线 + GEO 数据工作台），过程中 AI 给出的指标曾出现 453% 这种荒谬数值，是我定位出口径问题并修复的——最终所有数字可复现、经得起追问。
> 有能跑的作品和验证记录，希望有机会展示。

### 版本 C：简短流（微信快聊场景）

> 您好，AI 编程方向很匹配：我用 AI Agent 做了两个能跑通的小项目（AI 获客 pipeline + GEO 数据工作台，含可视化看板），全部数据可复现，也踩过并修掉 AI 输出的指标 bug。会 Git/MySQL，240/天可接受，方便发您看板吗？
